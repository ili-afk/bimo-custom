# BIMO Custom — мой форк BIMO

Привет. Я **Илья**, мне **16**, я из Москвы. Это мой проект — **BIMO Custom**.

Я беру за основу проект **[brenpoly/be-more-agent](https://github.com/brenpoly/be-more-agent)** —
домашнего говорящего робота на Raspberry Pi. Сначала я хочу **повторить оригинал один в один**,
чтобы убедиться, что база работает. А потом начну добавлять своё.

Идея простая: у оригинала есть то, чего не хватает другим — **живое лицо** на экране и голос.
А мне нужно ещё: **русский язык**, **ум из облака** и **управление моим ПК**.

---

## Что беру от оригинала

- Кодовое слово, распознавание речи, ответ голосом
- **Лицо на экране** (анимация по состояниям) — главная фишка
- Звуки (приветствие, «думаю», «услышал», ошибка)
- Память диалога
- Поиск в интернете

## Что убираю

- **Камеру и зрение** — они мне не нужны.

## Что добавлю (своя реализация)

- **Русский язык** с самого начала
- **Облачный мозг** (пока только облако — гибрид позже, он дороже)
- **Управление ПК** (открыть программу, нажать — как я сам)
- **Код и 3D** через облако
- **Экран двойного назначения**: лицо по умолчанию, а по запросу — нужная информация

---

## Железо

| Что | Что беру |
|---|---|
| Хост | **Raspberry Pi 5** (мало потребляет — можно носить/использовать вне дома) |
| Экран | с лицом (модель решу при покупке) |
| Микрофон | USB |
| Динамик | из донора |
| Камера | **не нужна** |
| Корпус | пока без корпуса, соберу на столе |

## Дорожная карта

| Версия | Что делаю |
|---|---|
| **v0.1** | **Ровно как у автора** — запускаю оригинал, ничего не меняя |
| v0.2 | Русский язык (речь, голос, промпт) |
| v0.3 | Облачный мозг |
| v0.4 | Управление ПК |
| v0.5 | Код и 3D |
| v0.6 | Экран: лицо ↔ информация |
| v0.7 | Доступ с телефона вне дома |

**Правило:** сначала копирую, потом меняю. Ни одного изменения, пока оригинал не заработает.
